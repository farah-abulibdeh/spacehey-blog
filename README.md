# [YOUR NAME]'s garden

A pastel Ottoman garden of a website: a character-sheet home page with a Levantine courtyard,
a recipe-card blog, a Habit Bakery (each day is a tiramisu layer), Seal Cove (floating notes +
an iceberg you can finally tip), Athan lanterns with a tasbih, and a Playbill of musicals,
shows, games and Club Penguin memories.

## Files
- `index.html`, `blog.html`, `habits.html`, `cove.html`, `athan.html`, `playbill.html`: the pages
- `garden.js`: the small script that makes the interactive parts work

No build step: open `index.html` in a browser. Hosted on Neocities: upload all the
`.html` files and `garden.js` to the root of your Neocities site (Dashboard → drag and drop).
`index.html` becomes your homepage.

Habit checks, tasbih counts, likes and Seal Cove notes are saved in each visitor's own browser.

## Personalise
Search for `[` in the HTML files and replace the `[YOUR NAME]`, `[City]` and other bracketed placeholders.
